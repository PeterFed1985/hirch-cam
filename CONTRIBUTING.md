# Contributing

Thank you for helping with Hirch CAM.

- **Bugs and ideas:** use *Milling › Send Feedback …* in the program. It can attach the drawing and a screenshot if
  you allow it. You can also open a GitHub issue. Please name your version (*Help › About*), your machine and its
  controller.
- **Code:** open a pull request against `main`. Run the tests first
  (`python3 -m pytest -q tests/ --ignore=tests/test_oberflaeche.py`). Code, comments and commit messages are mostly
  in German; English is fine too.
- **Translations:** the English texts are in `hirch_cam/sprache/en.json` (German → English).

By contributing you agree that your contribution is licensed under GPL-3.0-or-later.
